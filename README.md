# 창공전선 · Sky Frontline

브라우저에서 바로 하는 3D 공중전 게임 (three.js). 상업적으로 쓸 수 있는 3D 모델만 남겨서 **팔 수 있게 정리한 버전**이에요.

## 새로 들어간 것

- **39개 언어**: 처음 켜면 언어를 고르는 화면이 나와요 (메뉴 → 🌐 언어 · Language 에서 언제든 바꿀 수 있어요).
- **워썬더식 격납고**: 위쪽 출격 버튼과 모드 선택, 왼쪽 아이콘 줄, 오른쪽 접히는 패널(성능 · 도색 · 정비), 아래쪽 국가 탭(미국 · 소련/러시아 · 영국 · 독일 · 프랑스 · 일본 · 중국 · 스웨덴 · 대한민국 · 캐나다)과 기체 사진 카드.
- **격납고 음악 「출격 전야」**: 직접 작곡한 오케스트라 행진곡(호른 · 트럼펫 · 트롬본 · 현악 · 합창 · 팀파니 · 스네어). 녹음 파일 없이 게임 안에서 실시간으로 합성돼요. 비행 중에는 음악 없이 엔진 · 무전 · 경고음만 나와요.
- **설정 → 📜 크레딧 보기**: 모델 제작자 · 라이선스 · 음악 · 엔진 크레딧을 언제든 볼 수 있어요 (☰ 메뉴에도 있어요).
- **멀티플레이 아군 사격 금지**: 같은 편끼리는 총알 · 미사일 · 폭탄 피해가 안 들어가요.
- **유럽식 시골 마을 + 밭**: 박공지붕 집 · 교회 · 헛간 · 돌담 · 과수나무 · 시골길, 산울타리로 나뉜 밭. 집은 폭탄에 무너지고 들이받으면 추락해요.
- **배 항적**: 켈빈 파(19.5° 쐐기)와 프로펠러 거품 줄.

## 판매용으로 정리하면서 바뀐 점

- **다른 게임에서 뽑아낸 3D 모델은 하나도 없어요.** 설명에 War Thunder · Ace Combat · Battlefield 2 모드 · Cold Waters · Return to Castle Wolfenstein · World of Warplanes · Rise of Flight 에서 가져왔다고 적혀 있거나 "Not my model"이라고 적힌 모델은 전부 뺐어요.
- 깨끗한 모델이 예전에 있던 기체는 그 모델로 돌아갔고, 아직 없는 기체(MiG-21, F-104, 토네이도, 해리어, 스핏파이어 등)는 격납고 목록에서 빠졌어요. 미션에서 그 기체가 나올 자리에는 비슷한 깨끗한 기체가 대신 나와요.
- 헬기는 MH-60L 하나만 남았고, 지상전 전차는 게임 자체 전차 모델로 나와요.
- '카카리코 마을' 모델(젤다 게임에서 뽑아낸 것)은 빼고, 그 고원에 직접 만든 유럽 마을을 지었어요.
- 장난 기능은 뺐어요: 기관포 5초 연사 핵, 7667 무적 모드, 'L을 가져가' 춤.

## 크레딧 · 라이선스

게임에 쓰인 3D 모델은 Sketchfab 제작자들의 작품이에요. A-5 비질란테(helijah · Sketchfab Free Standard 라이선스)만 빼고 전부 **CC BY 4.0 / CC0** 라이선스라 제작자 표기를 지키면 상업적으로도 쓸 수 있어요. 모델별 제작자·출처·라이선스·바꾼 점은 [CREDITS.md](CREDITS.md)에 있고, 게임 안 설정 → 크레딧 보기와 엔딩 크레딧에도 나와요.

**이용 조건:** A-5 비질란테 모델은 봉인된 파일로 게임 안에서만 쓰여요. 어떤 형태로든 게임 밖으로 뽑아내거나 내려받아 복사·재배포·판매·재사용하는 건 금지예요. 나머지 모델은 [CREDITS.md](CREDITS.md)에 적힌 각 라이선스 조건대로만 다시 쓸 수 있어요.
