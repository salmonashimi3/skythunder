## 크레딧 · 라이선스
게임에 쓰인 3D 모델은 Sketchfab 제작자들의 작품이에요. A-5 비질란테(helijah · Sketchfab Free Standard 라이선스)만 빼고 전부 **CC BY 4.0 / CC0** 라이선스라 제작자 표기를 지키면 상업적으로도 쓸 수 있어요. 모델별 제작자·출처·라이선스·바꾼 점은 [CREDITS.md](CREDITS.md)에 있고, 게임 엔딩 크레딧에도 나와요.

**이용 조건:** A-5 비질란테 모델은 봉인된 파일로 게임 안에서만 쓰여요. 어떤 형태로든 게임 밖으로 뽑아내거나 내려받아 복사·재배포·판매·재사용하는 건 금지예요. 나머지 모델은 [CREDITS.md](CREDITS.md)에 적힌 각 라이선스 조건대로만 다시 쓸 수 있어요.
