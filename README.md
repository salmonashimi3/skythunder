# 창공전선 · Sky Frontline

브라우저에서 바로 하는 3D 공중전 게임 (three.js). 지금은 **팔지 않는 판**이라 기체가 전부 들어 있어요.

## 들어 있는 것

- **기체 전부**: 판매용으로 정리할 때 빠졌던 기체(MiG-21, F-104, 토네이도, 해리어, 스핏파이어, JA 37 비겐 등)와 헬기들이 원래 실사 모델 그대로 다시 들어왔어요.
- **새 기체 18대**: F-105D 썬더치프 · F-84F 썬더스트릭 · F11F-1 타이거 · MiG-27K · Su-7BMK · Su-17M4 · Yak-28B · 재규어 GR.1A · 시 해리어 FA.2 · 해리어 GR.3 · 시 빅슨 FAW.2 · 토네이도 F.3 · 미라주 5BA · 미라주 F1C · 보투르 IIB · 알파 젯 E · J-11B · F-15J. 그리펜 · MiG-29 · MiG-21 · MiG-23 · MiG-19 · Su-24는 더 실사 모델로 바뀌었어요.
- **1인칭 조종석**: 각 기체 자기 모델의 조종석만 보여요 (다른 조종석 모델을 겹쳐 넣지 않아요). 조종사 눈 위치를 기체마다 다시 맞춰서 계기판이 보이고, 그늘에서도 계기가 읽히게 살짝 밝혀 놨어요.
- **백미러**: 조종석에 거울이 달린 기체(Su-27 계열, MiG-29, 토네이도, 그리펜, 미라주, F4U 콜세어, 스핏파이어 등)는 1인칭에서 그 거울에 뒤쪽이 실시간으로 비쳐요. 위 가운데 거울엔 조종사 헬멧이 보여요.
- **해상 불시착**: 바다에 내려앉으면 충격에 조종사가 정신을 잃어요 (화면이 까매지고, 깨어나도 한동안 흐릿해요). 깨어나면 가라앉기 전에 E×3으로 탈출하세요. 기체 안에서 물에 잠기면 화면이 탁한 초록빛으로 어두워져요.
- **걸프 사막 맵**: 북서풍을 따라 늘어선 모래언덕(완만한 바람받이 면과 가파른 미끄럼면), 바람 자국, 사막 자갈, 모래 물결 무늬, 낮게 날면 보이는 덤불과 돌.
- **AC-130U 건쉽**: 왼쪽 옆으로 쏘는 25mm GAU-12 · 40mm 보포스 · 105mm 곡사포를 사수들이 지상 목표에 쏴요. P.108A엔 방어 기총 사수가 붙었어요.
- **애프터버너 불꽃**: 모든 제트기가 애프터버너를 켜면 노즐에서 불꽃이 나와요 (원래 애프터버너가 없는 기체는 불꽃만 나오고 추력은 그대로).
- **39개 언어**: 처음 켜면 언어를 고르는 화면이 나와요 (메뉴 → 🌐 언어 · Language 에서 언제든 바꿀 수 있어요).
- **워썬더식 격납고**: 위쪽 출격 버튼과 모드 선택, 왼쪽 아이콘 줄, 오른쪽 접히는 패널(성능 · 도색 · 정비), 아래쪽 국가 탭과 기체 사진 카드.
- **폭발**: 여러 덩어리로 부풀며 하얀 중심에서 그을음으로 식는 불덩이, 연기 꼬리를 끄는 불붙은 파편, 땅에선 흙기둥 · 바다에선 물보라, 가까운 폭발엔 화면 흔들림.
- **격납고 음악 「출격 전야」**: 직접 작곡한 오케스트라 행진곡. 녹음 파일 없이 게임 안에서 실시간으로 합성돼요. 비행 중에는 음악 없이 엔진 · 무전 · 경고음만 나와요.
- **설정 → 📜 크레딧 보기**: 모델 제작자 · 라이선스 · 음악 · 엔진 크레딧을 언제든 볼 수 있어요 (☰ 메뉴에도 있어요).
- **멀티플레이 아군 사격 금지**: 같은 편끼리는 총알 · 미사일 · 폭탄 피해가 안 들어가요.
- **유럽식 시골 마을 + 밭**: 박공지붕 집 · 교회 · 헛간 · 돌담 · 과수나무 · 시골길, 산울타리로 나뉜 밭. 집은 폭탄에 무너지고 들이받으면 추락해요.
- **배 항적**: 켈빈 파(19.5° 쐐기)와 프로펠러 거품 줄.

## 크레딧 · 라이선스

게임에 쓰인 3D 모델은 Sketchfab에 올라온 작품이고, 일부는 업로더가 **다른 게임(War Thunder 등)에서 뽑아낸 모델**이에요. 그래서 이 판은 **팔거나 상업적으로 쓰면 안 돼요**. 모델별 제작자·출처·라이선스·바꾼 점은 [CREDITS.md](CREDITS.md)에 있고, 게임 안 설정 → 크레딧 보기와 엔딩 크레딧에도 나와요.

**이용 조건:** A-5 비질란테 모델은 봉인된 파일로 게임 안에서만 쓰여요. 어떤 형태로든 게임 밖으로 뽑아내거나 내려받아 복사·재배포·판매·재사용하는 건 금지예요. 나머지 모델도 [CREDITS.md](CREDITS.md)에 적힌 각 라이선스 조건대로만 다시 쓸 수 있고, 다른 게임에서 뽑아낸 모델은 다시 쓰면 안 돼요.
